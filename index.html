Sources & References

The collection includes Qur’an-based supplications and hadith-based supplications, with the cited source shown on each entry. The original 119-entry collection is retained, and additional Qur’an-based entries have been added as a separate expanded set. Hadith numbering can vary between editions and websites, so the collection should be checked against a trusted printed or scholarly source when exact numbering matters.

Important: A reference identifies the source; it is not a substitute for scholarly verification. If you notice a wording or reference that needs correction, verify it before relying on it.

Source & Verification Note

This collection distinguishes Qur’anic supplications from supplications reported in the Sunnah. References have been normalized where possible and unsupported generic wording has been replaced with source-based supplications. For religious publication, the Arabic text and reference should still be checked against the cited primary source before treating an entry as independently scholar-verified.
